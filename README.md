# ShitShat
crappy vibe-coded chatroom webapp generated by an expensive clanker (gpt-6 instant) for testing it out

pretty much told it to make a basic website chat in the corner using Trystero and kept prompting in more features.

Trystero's a P2P project that uses decentralised services to form the connection between peers (rather than having a script on your server do that for you). 
 this basically means you can connect people together without having to do anything on a server.

feel free to use this project if you want. it's rather ugly, but it works. I did it because I was curious about ChatGPT and wanted to see Trystero in action for a while. 
 the second, bigger reason is because I LOOOOVE chatrooms on random websites that you used to visit back in like 2014, where you enter and there's just people (who like a certain thing) there.

chat is deliberately ephemeral, apparently e2e encrypted, no login, very basic spam filters, can probably be exploited very easily - but it'S FUN!!!!! remember FUN that used to be in websites???

- reasoning -
intended to be a bit like the old Faceblox chat or the Skysa Footer Chat (I loved this one) you got in sites back in 2014. users just went on a site (albeit they had to make an account), and suddenly you could talk to people. it was like entering a place.

nowadays Discord has superseded this for communities (quite well) and public servers will soon be searchable (opt-in) which is a big plus - accessibility is my favourite thing for any site. my god is it so much better than what Skype devolved into. I do still wish websites had built-in fun chats though. that being said, WidgetBot kinda does what this crappy chat does but with Discord integration anyway (though you have to pay for it and setup a bot).

but there will always be a part of me that is going on about simple fun and trying to meet that with modern day security challenges.
